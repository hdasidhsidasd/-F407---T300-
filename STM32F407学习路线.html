STM32F407（Cortex-M4）学习路线总览
基于「普中F407-定通-T300（麒麟F407）开发板」光盘资料整理 · 主线为 6 个阶段 + 按兴趣进阶
主线选择（二选一，中途可切换）：
推荐：HAL 库版 —— MP4 视频（手把手带你学STM32–HAL库版）+ 7-基础实验–HAL库版 + 开发攻略 V2.0 HAL库版；更适合新学、工程更规范。
对照：标准库版 —— AVI 视频（普中STM32F407开发板视频教程）+ 1-基础实验（标准库）+ 开发攻略 V2.2 标准库版；经典教学、网上资料最多。
通用建议：
第 1～2 阶段建议用寄存器实验理解底层（实验 1、2、5、6），之后再切入库函数 / HAL 库提效；每个实验遵循「先跑通例程 → 看懂代码 → 自己重写 → 改功能」四步。
节奏参考：每周 2～3 个实验，约 2～3 个月走完主线。
第 0 步 · 环境准备（先做，别跳过）
阅读「1--用户必看」：开机体验 + 入门教程 + KEIL5安装 + 仿真器使用；安装 KEIL5（MDK528）+ STM32F4xx_DFP 器件包 + CH340 驱动；用 PZ-ISP 或仿真器点亮板载例程。
阶段 1 · 芯片认知与工程基础 （视频 1–6 章 / AVI 1–7 集）
STM32 是什么 / 命名规则 最小系统（晶振/复位/电源/下载） 存储器映射与寄存器 C 语言指针/结构体操作寄存器 建第一个工程模板
资料：2--开发板原理图（对照实物）· 8--STM32相关资料（参考手册/权威指南）· 实验 1-寄存器模板创建
阶段 2 · GPIO 与库函数入门 （实验 1–9 · 视频 6–15 章）
寄存器点亮 LED GPIO 结构与 8 种模式 位带操作 时钟系统（时钟树） SysTick 延时 蜂鸣器 / 按键 ★ 固件库/HAL 库模板 → 库函数点灯
此阶段结束时应能独立搭建工程、看懂库函数调用链（HAL_GPIO_Init / GPIO_InitStructure）。
阶段 3 · 中断与定时器 （实验 10–12 · 视频 16–19 章）
NVIC 中断系统 外部中断 EXTI 定时器中断（时基单元） PWM 呼吸灯
核心理解：中断优先级抢占/响应、定时器预分频–计数–自动重载的算时间方法。
阶段 4 · 通信、模拟外设与低功耗 （实验 13–26 · 视频 20–34 章）
USART 串口 + printf 重定向 独立/窗口看门狗 输入捕获 / 电容触摸按键 ADC / 内部温度 / 光敏 DAC / PWM-DAC DMA RTC 实时时钟 随机数 / 待机唤醒
串口 + DMA 是嵌入式调试与数据搬运的基石，建议练到能不看例程写出来。
阶段 5 · 总线接口与存储 （实验 27–39 · 视频 35–48 章）
I2C–EEPROM / DS18B20 红外遥控 / RS485 / CAN FSMC–TFTLCD / 触摸屏 SPI–FLASH / 内部 Flash MPU6050（I2C+DMP） FSMC–外扩 SRAM 内存管理
本阶段结束即掌握嵌入式两大主流总线（I2C/SPI）与工业总线（CAN/RS485），可以接各种传感器与屏。
阶段 6 · 综合应用与文件系统 （实验 40–52）
SDIO–SD 卡 + FATFS 文件系统 FLASH 字库 / 图片解码 音乐播放器 / 录音机 / 视频播放 拼音输入法 / 串口 IAP 升级 USB SLAVE 读卡器 / HOST U盘 / 鼠标键盘 LwIP 以太网
选 2～3 个做综合项目收尾（推荐：数码相框、音乐播放器、USB读卡器），把前面外设串起来。
